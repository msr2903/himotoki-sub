## Findings fixed before merge

| Finding | Resolution |
| --- | --- |
| Circular model imports crashed the content script with a “before initialization” error. | Moved cross-model video wiring into initialization and coverage derivation into its own model. |
| Existing dictionary installations failed every lookup because they lacked the new pitch/frequency/JLPT columns. | Detect optional columns and select null aliases for older schemas. Confirmed against both database versions. |
| Sentence breakdown could send per-word requests through the online fallback despite being described as local. | Use a local batch lookup and show an installation message when the dictionary is missing. |
| Clip replay used elapsed wall-clock time and depended on popup lifetime. | Stop at the video's media time; cancel obsolete replay listeners. |
| Late caption lookups could overwrite current coverage; missing dictionaries left “Analyzing…” displayed. | Accept results only for the current caption array, reset stale results, and expose missing/error states. |
| Coverage could count unresolved cues as i+1; unresolved lookups could become known-word keys. | Exclude unresolved cues from i+1 and reject unresolved/error translations as known words. |
| Alternate popup entries could request the primary entry's conjugations. | Use the selected entry's sequence and reset expanded sections when switching. |
| Known-word opacity affected the popup; breakdown columns/scaling could overflow. | Keep active tokens undimmed and correct the grid and scaling. |
| Settings redesign conflicted with newly merged known-word controls. | Preserve the toggle, known-word count and reset control in the new layout. |
| Narrow settings layouts and online-lookup disclosure needed adjustment. | Stack controls on narrow windows and accurately describe the dictionary fallback. |
| Roadmap described merged work as pending and contained stray tool markup. | Update shipped status, distinguish remaining testing work, and remove markup. |

The dictionary smoke test previously printed success even when all lookups failed. It now asserts successful messages, required lookups, conjugation output, segment repair, enrichment data when supplied, and lookup persistence after relaunch. `pnpm test` now runs a deterministic browser regression suite instead of invoking an unavailable Vitest suite.
