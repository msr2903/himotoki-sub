## Name

Himotoki Sub – Learn Japanese from subtitles

## Summary (132 chars max)

Japanese subtitles split into words, with an instant offline dictionary, furigana and one-click saving to Himotoki or Anki.

## Description

Himotoki Sub turns the Japanese subtitles on YouTube, Netflix and other video sites into a study tool.

• Every subtitle line is split into words by a local model, so you can see where words begin and end.
• Hover a word for furigana and a short meaning; click it to pin a full dictionary entry with readings, senses and part of speech.
• Lookups are instant and offline once you download the Jitendex dictionary (about 38 MB).
• Save words with the sentence, video link and timestamp to your Himotoki account, or send them to Anki.
• Rewind by subtitle with the arrow keys, pause while hovering, adjust size and position.
• Optional whole-line translation via Google Translate or DeepL.

Hover and click actions are configurable: furigana, meaning, both, pop-up dictionary, or nothing.

Dictionary data: Jitendex (CC BY-SA 4.0), built from JMdict (EDRDG) and Tatoeba.

Justify `offscreen` (runs the model and database), `unlimitedStorage` (offline dictionary), `identity` (optional Google sign-in).

## Stable extension ID

`manifest.js` embeds a public `key`, so the unpacked extension always gets the same ID. The matching private key lives outside the repository at `~/.himotoki-sub/extension-key.pem`; keep it, it is needed if you ever pack a `.crx` yourself. When the extension is first uploaded to the Web Store, the store assigns its own ID unless you upload a package signed with this key. For Save to Himotoki sign-in, add each ID you end up with (unpacked: `hikpeplieggpeefjmdlbgkfeoaabaloi`, plus the store ID once published) to the `himotoki` project's Google Web client under **Authorized redirect URIs** as `https://<id>.chromiumapp.org/`.
